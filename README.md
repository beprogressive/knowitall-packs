# KnowItAll language packs

Language data for the KnowItAll browser extension. The extension downloads a pack from this
repository's releases when a language is enabled, and the dictionary of a language pair when a
language is translated into its target; it verifies each file's size and SHA-256 checksum and
keeps it on the device. These files are generated by the extension's pack build script; do not
edit them by hand.

## Format

A pack is a gzip-compressed "KIAP" file (format 1): a JSON metadata header with the language,
version, license and sources (each with the full license notice it requires), followed by one
table of lowercase word forms sorted in UTF-16 code unit order. Each form refers to its lemma,
which is a form of the same table, and has a frequency rank (0 when it is not in the language's
frequency list).

A dictionary is a gzip-compressed "KIAD" file (format 1): the same kind of metadata header, with
the source and target languages, followed by the lemmas of the source language's pack sorted in
UTF-16 code unit order, each with its entry: the translations into the target language, grouped
by part of speech and by meaning in the order of the source.

### English → Russian dictionary, version 1

License: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).

- **English Wiktionary (kaikki.org extract of 2026-10-30)** — https://kaikki.org/dictionary/English/
  - Authors: English Wiktionary contributors; extracted with Wiktextract by Tatu Ylonen and published by kaikki.org
  - License: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/)
  - Changes: Only the translations into Russian of the lemmas of the English language pack, from the translation tables of their own entries, grouped by part of speech and by table (one meaning each) in page order; glosses, transliterations, grammatical tags and the names of letters left out, cells split into their translations, stress marks, markup, affixes and parsing artifacts removed, repeated translations and meanings merged. A word without translations of its own takes those of a current spelling variant (colour → color), never of an abbreviation or an obsolete form. A word with neither takes those of its capitalized headword (english → English; of a single letter only the pronoun, i → I); a word with its own but no adjective takes only the adjective of its capitalized headword (afghan → Afghan). Names, abbreviations, initialisms, acronyms and contractions of a capitalized headword are never taken.
